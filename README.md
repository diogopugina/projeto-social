🌐 Projeto Redes Sociais
Projeto desenvolvido durante meus estudos de Desenvolvimento Web, utilizando HTML5 e CSS3.

📌 Sobre o projeto
Este projeto apresenta uma interface interativa com acesso a diferentes páginas de redes sociais, permitindo explorar suas respectivas representações dentro de um ambiente web.

🛠️ Tecnologias utilizadas
HTML5
CSS3
📂 Estrutura do projeto
index.html — página inicial.
home.html — página principal.
facebook.html — página do Facebook.
instagram.html — página do Instagram.
github.html — página do GitHub.
twitter.html — página do Twitter.
youtube.html — página do YouTube.
style.css — estilos do projeto.
imagens/ — imagens utilizadas.
stilo/ — arquivos complementares de estilo.
🚀 Acesse o projeto
Visualize o projeto publicado:

https://diogopugina.github.io/projeto-social/

🎯 Objetivo
Praticar conceitos de estruturação HTML, estilização CSS, organização de arquivos e navegação entre páginas.
